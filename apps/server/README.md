# Mail server

This is the operator side of NightMail, in Node and TypeScript. One process (`npm run mail-server -w apps/server`) receives mail over SMTP, stores it encrypted for each address, serves the mailbox API the app downloads mail from and the delivery API between NightMail addresses, issues plans, advances the registry rounds and relays the app's proofs to the chain. It never holds your private keys. It also does not hold the operator wallet: that lives in the payer (`npm run operator-wallet -w apps/server`, `src/bin/operator-wallet.ts`), a separate process the server asks to pay over a local Unix socket. The desktop app reaches the server over HTTP, and the server reads the chain through the Midnight indexer. It uses `packages/core-ts` for mailbox cryptography and `packages/midnight` for the registry. For setup and the other commands (`deploy-contracts`, `fund-night`, `send-night`), see the [root README](../../README.md).

**Run its tests** (from the repository root, with the contracts compiled): `npm test -w apps/server`. The devnet and end-to-end suites (`npm run test:devnet -w apps/server`, `npm run test:e2e -w apps/server`) need the local network running (the end-to-end one also needs the payer and the mail server) and take much longer.
