# Test vectors

This folder holds shared known-answer data, so that the TypeScript and Rust implementations of NightMail produce the same bytes. It is not a package and contains no code to run, apart from one generator. `contract/` has the `NightMailRegistry` hash results, written by `npm run vectors -w contracts` and read by the `packages/midnight` tests. `crypto/` has mailbox encryption, request signing, key derivation, name encryption and mail between addresses: `packages/core-ts` writes most of it and `crypto/gen-keys.mjs` writes `keys.json` and `name-cipher.json`, and the desktop app's Rust core replays it in its tests. `issuer/` has a signed plan receipt, checked by both the server tests and the Rust core. `rpc/` has example JSON-RPC messages between the desktop app and the helper process, read by the helper's tests and the Rust core. The exact byte-level protocol spec is in [`crypto/README.md`](crypto/README.md). For setup, see the [root README](../../README.md).

**Run its tests**: the vectors are checked by the tests of the packages that read them. To check that `keys.json` and `name-cipher.json` are up to date, run `node packages/test-vectors/crypto/gen-keys.mjs --check` from the repository root.
